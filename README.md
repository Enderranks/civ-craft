# Pizza Rush Minecraft Mod

A small Fabric mod for Minecraft 1.20.1. It adds:

- Pizza Slice food
- Delivery Pizza food with a chance of short speed boost
- Pizza Oven block
- Survival recipes for all new items

## Build

Use Java 17, then run:

```powershell
.\gradlew.bat build
```

The finished mod jar appears in `build/libs/`.

## Install

Install Fabric Loader for Minecraft 1.20.1, add Fabric API, then place the generated `pizzarush-1.0.0.jar` into your Minecraft `mods` folder.
